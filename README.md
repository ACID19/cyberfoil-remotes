# CyberFoil remote index

A filtered copy of the public OpenNX directory list for CyberFoil.

Included sources:
- Ghost eShop PUBLIC
- Ghost eShop RETRO
- NX Saves

The index contains public catalog addresses only. It does not host game files or contain login credentials. Catalog and download availability depend on each source.

Source format: https://cyberfoil.foo/shop.html
Original list: https://opennx.github.io/cyberfoil.json
